# Impact of the internet — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 3 Operating online, Chapter 7 Impact of the internet** (book pages 109–131). Only these pages are covered.

Each section is explained step by step with interactive simulations, followed by the book's **activities** (where the book has them) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes, including all 13 chapter questions on page 131).

**Part A · Impact on individuals** (pages 109–121)

1. The internet and protocols — connected devices vs connected content; IMAP, FTP, SSH, VoIP, XMPP, HTTP → ✓ Check
2. Information and services — TV and radio vs the internet (Table 7.1), booking, shopping, banking, VLEs, on-demand, Web 2.0, memes → Activities → ✓ Check
3. Employment — skill requirements, new job opportunities, job losses → Activities (Table 7.2) → ✓ Check
4. Working practices — collaborative, flexible and mobile working → ✓ Check
5. Social impact — Facebook ‘population’ (Figure 7.2), social interaction, filter bubbles, cyberbullying, physical activity → Activities → ✓ Check
6. Staying safe online — zip it, block it, flag it; Report Abuse; digital footprint → Activities → ✓ Check
7. Working from home — office → LAN → internet, commute savings, benefits and drawbacks scales → Activities → ✓ Check
8. Test Part A

**Part B · Impact on organisations and society** (pages 122–131)

9. Positive impacts — charity communication (Figure 7.12), global markets, global workforce and time zones (Figure 7.13), big data → Activities → ✓ Check
10. Negative impacts — data leaving the building, unauthorised access and defences, greater competition → Activities (Table 7.3) → ✓ Check
11. The digital divide — Figure 7.15, causes of unequal access, impact of limited access → Activities (Table 7.4) → ✓ Check
12. Less restricted access to networks — the media, moderators, user-generated content, 2011 riots, Ushahidi → ✓ Check
13. Information gap and socialising — information rich and poor, SMS for farmers, status updates → ✓ Check
14. Test Part B · Key terms (searchable)

**Progress that students can share and resume** (same system as the other lessons)

- Saved automatically in the student's browser (`localStorage`, key `ii-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`II1Z.…`) to carry on with another device.
- Nothing is sent to a server. People, messages and websites in the simulations are made up; regional internet figures are approximate (about 2016).

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#safety` or `#check-divide`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
